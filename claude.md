This tool is a file compressor that uses the LZ77 algorithm to compress files. It can compress files up to 100 MB in size. The compression rate is very good, and the decompression rate is also very good. The compression algorithm is very fast, and the decompression algorithm is also very fast. This tool is very useful for compressing files before sending them over the internet, or for compressing files before sending them to someone who does not have a computer. The tech stack used will be a React Frontend, a Node Backend, with Express backend. There will be no databases used. It should return the compressed file as a download.
